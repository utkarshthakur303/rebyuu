# Reviewed 2026-08-24. Re-review whenever a route is added to
# src/app/App.tsx, or when the /browse filter params in BrowsePage.tsx
# change.
#
# FORMATTING NOTE — read before editing.
# Every rule below sits flush against its "User-agent:" line, with no blank
# lines and no comment lines in between, and this is deliberate. RFC 9309
# permits blank lines inside a group, and Google's parser honours that. The
# older 1996 draft does not: it treats a blank line as a record terminator,
# and a comment-only line strips to empty and terminates it too. Parsers
# built to the old draft (Python's urllib.robotparser among them) will
# silently drop every rule in a group that has one. That failure is
# invisible in Search Console — Google reads the file correctly — while the
# crawlers most likely to hammer the facet URLs below are exactly the ones
# running naive parsers. So: keep the commentary up here in the header, and
# keep each group a contiguous block.
#
# ---------------------------------------------------------------------
# GROUP 1 — everything not named in a later group.
#
# That deliberately includes Googlebot, Bingbot and every AI answer-engine
# crawler: GPTBot, OAI-SearchBot, ChatGPT-User, ClaudeBot, Claude-User,
# Claude-SearchBot, PerplexityBot, Perplexity-User, Google-Extended, CCBot.
#
# Rebyuu wants AI answer-engine citation traffic — an assistant citing and
# linking back to a rebyuu.app page is the same value proposition as an
# organic search referral, so none of those are singled out for a block.
# They are deliberately NOT given their own "Allow: /" group: a crawler
# obeys only the single most specific group that names it, so giving GPTBot
# its own group containing just "Allow: /" would silently exempt it from
# every Disallow below. Leaving them unnamed means they fall through to
# this group and inherit the same rules as everyone else.
#
# The /browse rules are the faceted crawl trap. /browse itself is public
# and worth crawling: it is the catalogue entry point and links out to
# individual title pages. Its filtered variants are not. BrowsePage.tsx
# reads seven params from the URL — genre, year, season, status, sort,
# page and q — and every combination renders a distinct 200. Treating
# genre as single-select that is ~296,000 URLs; with real multi-genre
# selection and free-text q it runs into the hundreds of millions, all of
# it near-duplicate reorderings of the same catalogue.
#
# "?" is a literal character in robots.txt, not a wildcard, so "/browse?"
# matches every query-string variant while leaving the bare path alone.
# "Allow: /browse$" is redundant under both parsers but states the intent.
#
# /login, /profile, /lists and /admin hold no unique content for an
# anonymous crawler; /profile and /lists are behind ProtectedRoute and
# /admin behind AdminRoute (session + is_admin).
#
# /app.html is the bare React shell. Every SPA route rewrites to it, but the
# file itself is also directly reachable and would be an empty duplicate of
# the homepage if a crawler found it, so it is disallowed. It exists under
# that name rather than index.html because Vercel resolves the filesystem
# before rewrites: while dist/index.html existed, "/" was satisfied by the
# static file and never reached the prerender function.
#
# / and /anime/:id (~22k title pages) are intentionally NOT disallowed.
# Only a quality-gated subset is submitted via the XML sitemap, but any
# /anime/:id page reachable through internal links stays crawlable, so
# Google can evaluate and promote one into the submitted tier later
# without needing a robots.txt change.
#
# ---------------------------------------------------------------------
# GROUP 2 — ByteDance's crawler, fully blocked. A documented history of
# ignoring crawl-delay and robots directives, and negligible answer-engine
# citation value for this audience compared to the crawlers allowed above.
# Revisit if that changes.
# ---------------------------------------------------------------------

User-agent: *
Allow: /browse$
Disallow: /browse?
Disallow: /browse/?
Disallow: /login
Disallow: /profile
Disallow: /lists
Disallow: /admin
Disallow: /app.html

User-agent: Bytespider
Disallow: /
